Phoenix Code Cup

Rules & Overview

Teams of 3–4 students have two hours to solve eight programming problems at Florida Polytechnic University in Lakeland. Teams are ranked by the number of problems solved.

Team size
3–4 students
Time limit
2 hours
Problems
8
Languages
C/C++, Python 3, Java

Overview

Teammates write code together in an IDE and submit their solution files to a judging website for checking. Teams may use any mix of the supported languages, including switching between problems.

  • Participation is free. Lunch is provided.
  • Schools arrange their own transportation.
  • Each student can only be on a single team.
  • Registration and parent consent forms must be submitted by November 22, 2026. Register your team · Parent consent form

Competition Rules

  • Student teams may not communicate with other teams during the competition.
  • Web browsers may be used only to access the submission website.
  • Each team may bring up to 25 pages of printed or handwritten notes for reference.
  • No generative AI of any kind, including AI features built into IDEs. Any violation results in immediate disqualification.

Equipment & Setup

  • Each team must provide a single Wi-Fi–enabled laptop.
  • Install and test your programming language, runtime and IDE before arriving. Turn off any AI assistants.
  • Login credentials for the submission website will be provided at the start of the competition.

Sample Problem

Hello World

Every programmer's first program prints “Hello world.” In this problem, you'll turn a list of words into hello statements.

Input: The first line contains an integer N (1 ≤ N ≤ 100). Each of the next N lines contains an ASCII string s.

Output: For each string s, print Hello s! on its own line.

Sample input
3
world
bob
alice
Sample output
Hello world!
Hello bob!
Hello alice!
